# Portfolio professionnel

Ce dossier est prêt pour GitHub Pages.

## Publication

1. Ouvrez votre dépôt `abdellatifelmendery-spec.github.io`.
2. Cliquez sur **Add file**, puis **Upload files**.
3. Envoyez les fichiers `index.html`, `style.css`, `script.js` et le dossier `images` de ce dossier.
4. Dans **Settings > Pages**, choisissez la branche `main` et le dossier `/(root)`.
5. Remplacez `votre-email@example.com` dans `index.html` avant de publier.

Votre site sera disponible à l'adresse `https://abdellatifelmendery-spec.github.io`.
